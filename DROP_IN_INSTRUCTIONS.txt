READING LIST + GLOSSARY — DROP-IN
==================================
Two new pages, each with bundled content (works offline). Terminal-copy method.

STEP 1 — Upload this folder into the Codespace (drag into file explorer).
         It appears as "reading-glossary".

STEP 2 — The data folder is NEW, so create it first, then copy all files:

  cd /workspaces/CodeWithoutLimitsNET
  mkdir -p apps/web/src/data
  cp reading-glossary/apps/web/src/data/reading-list.json apps/web/src/data/reading-list.json
  cp reading-glossary/apps/web/src/data/glossary.json     apps/web/src/data/glossary.json
  cp reading-glossary/apps/web/src/pages/ReadingList.jsx  apps/web/src/pages/ReadingList.jsx
  cp reading-glossary/apps/web/src/pages/Glossary.jsx     apps/web/src/pages/Glossary.jsx
  cp reading-glossary/apps/web/src/main.jsx               apps/web/src/main.jsx
  cp reading-glossary/apps/web/src/components/Layout.jsx  apps/web/src/components/Layout.jsx

STEP 3 — Verify all landed (should print all four filenames, no errors):

  ls apps/web/src/data/glossary.json apps/web/src/data/reading-list.json apps/web/src/pages/ReadingList.jsx apps/web/src/pages/Glossary.jsx

STEP 4 — Build, commit, push:

  npm run build:web
  git add .
  git commit -m "Add reading list and glossary pages"
  git push

STEP 5 — Render: codewithoutlimitsnet-1 -> Manual Deploy
  -> Clear build cache & deploy. Hard-refresh (Ctrl+Shift+R).

WHAT YOU GET
  - Two new nav links: "Reading list" and "Glossary".
  - Reading list: 5 free textbooks + open online courses grouped by subject,
    each with working links and the "verified on" date.
  - Glossary: all 17 terms (Bandwidth, Throughput, Token, Hallucination, etc.)
    with short + full definitions, examples, cited sources, and instant search.
  - Both work offline once loaded (content is bundled, no server call).
